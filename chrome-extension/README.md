# Smarters IPTV Web Player — Chrome Extension

A fast, lightweight, and modern browser extension for streaming HLS (`.m3u8`), IPTV M3U playlists, and Xtream Codes API channels directly inside Google Chrome or Chromium-based browsers.

---

## 🚀 How to Install and Test Locally in Chrome

1. Open **Google Chrome**.
2. Navigate to `chrome://extensions/` in the address bar.
3. Toggle on **Developer mode** in the top-right corner.
4. Click **Load unpacked** in the top-left corner.
5. Select the folder:
   ```
   C:\Users\hp\OneDrive - Université Privée de Marrakech\Desktop\iptvthesmarters\chrome-extension
   ```
6. The extension **"Smarters IPTV Web Player — HLS, M3U & Xtream"** will appear in your installed extensions list.
7. Click the extension icon in your Chrome toolbar (pin it for quick access):
   - **Tab 1 (HLS Stream):** Click one of the quick test chips (e.g. *Mux BigBuckBunny* or *Akamai 1080p*) to verify instant video playback and health diagnostics.
   - **Tab 2 (Xtream API):** Enter any Xtream Codes Host, Username, and Password to load live categories and stream channels.
   - **Tab 3 (M3U Playlist):** Paste an M3U playlist URL or drop a `.m3u` file to parse and play channels.
   - **Full Tab Mode:** Click the expand icon in the top header to launch the full-screen desktop web player (`player.html`).
